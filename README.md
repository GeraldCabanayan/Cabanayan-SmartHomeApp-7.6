Smart Home App

A React Native and Expo-based Smart Home application designed to provide a user interface for monitoring sensors and controlling IoT devices.

Overview

The Smart Home App provides a frontend interface for interacting with smart home devices and monitoring sensor information. 
The application uses React Native with Expo and is organized using navigation, context-based state management, and IoT service structures.

The frontend is designed to be connected to a backend for actual IoT device communication and data management.

Features: 
  - Dashboard for smart home information
  - IoT device management
  - Device status controls
  - Gateway connection status
  - Sensor monitoring
  - Sensor data refresh
  - Loading indicators
  - Error handling
  - React Context API for IoT state management
  - IoT service structure for backend integration
  - Drawer/navigation-based application structure
